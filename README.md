# 🌴 HH Goa 2026 - Builder Photobooth Pro Studio

An ultra-aesthetic, interactive web application to create, customize, and download official **HH Goa 2026 Builder VIP Passes**.

## ✨ Features

- **✨ 3D Interactive Parallax Physics**: Realtime 3D tilt and specular shimmer light reflection tracking mouse movement over the pass.
- **🏷️ Sticker & Badge Overlay Studio**: Stamp retro developer stickers (`AI Pioneer`, `Goa Local`, `Built in 24h`, `Coffee Fueled`, `Agentic Wizard`, `Web3 Diamond`) on your pass.
- **🎨 3 Curated Aesthetic Themes**: Switch between `Emerald`, `Cyber Neon`, and `Sunset` dark-mode glassmorphic themes.
- **🪪 4 High-DPI Pass Templates**:
  - **Goa VIP Pass**: Bright tropical badge with holographic stamps & gold stars.
  - **Creative License**: Polaroid paperclip photo, aged paper texture & wax seal.
  - **Cyber Terminal**: Matrix grid, dark mono aesthetic & active status line.
  - **Sunset Club**: Luxurious sunset gradient card with gold foil frame.
- **🔊 Web Audio Synthesizer Sound FX**: Retro camera shutter click, button pops, and sticker stamp sounds (with mute toggle).
- **📸 Flexible Photo Source**: Webcam capture with 3s countdown timer, local photo file upload, or sample avatar gallery.
- **📐 Multi-Resolution Export**:
  - **4K Ultra HD PNG** (3000 × 1890 px).
  - **Instagram / X Story (9:16 Vertical)** (1080 × 1920 px wallpaper layout).
  - **Standard PNG** & One-Click Clipboard Copy.

## 🛠️ Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Dev Server
```bash
npm run dev
```
Open [http://localhost:3000/](http://localhost:3000/) in your browser.

### 3. Build for Production
```bash
npm run build
```
